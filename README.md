# Ассистент для творческого письма (Creative Writing Assistant)

Умный чат-бот, разработанный специально для авторов книг и сценаристов, предоставляющий функции генерации персонажей и помощи в творческом письме с поддержкой нескольких языков.

## Обзор проекта

Ассистент для творческого письма — это веб-приложение на основе искусственного интеллекта, интегрированное с API Spark Large Model, которое предоставляет авторам и сценаристам следующие основные функции:

- **Многоязычный интерфейс чата**: поддержка китайского и русского языков
- **Генерация персонажей**: автоматическое создание полной информации о персонажах (имя, внешность, характер и т.д.)
- **Творческая помощь**: генерация названий книг по описаниям и наоборот
- **Экспорт документов**: экспорт информации о персонажах в формате PDF
- **Генерация изображений**: создание аватаров для персонажей

## Функциональные возможности

### 🎭 Генерация персонажей
- Автоматическая генерация имен (фамилия, имя, город)
- Поддержка различных жанров и стран/регионов (Россия, Англия и др.)
- Поддержка фэнтези-тематики (эльфы, гномы и др.)
- Полные атрибуты персонажа: пол, возраст, рост, вес, цвет волос, цвет глаз, профессия, черты характера

### 💬 Умный чат
- Поддержка многоязычного диалога (китайский/русский)
- Интерфейс реального времени
- Управление историей чата
- Кнопки быстрого доступа

### 📄 Управление документами
- Экспорт карточек персонажей в формате PDF
- Генерация и загрузка изображений
- Функции управления файлами

### 🌐 Технические особенности
- Адаптивный дизайн для настольных и мобильных устройств
- Связь в реальном времени через WebSocket
- Интерфейсы RESTful API
- Поддержка кросс-доменных запросов

## Документация API

### Интерфейс генерации текста

**Конечная точка**: `POST /api/generate`

**Параметры запроса**:
```json
{
  "prompt": "Сгенерировать описание фэнтези-персонажа",
  "language": "ru"
}
```

**Ответ**:
```json
{
  "success": true,
  "message": "Сгенерированное текстовое содержимое",
  "character": {
    "name": "Имя персонажа",
    "description": "Описание персонажа"
  }
}
```

### Интерфейс генерации изображений

**Конечная точка**: `POST /api/generate-image`

**Параметры запроса**:
```json
{
  "prompt": "Красивый эльф-воин",
  "size": "1024x1024"
}
```

**Ответ**:
```json
{
  "success": true,
  "image_url": "/files/generated_image.jpg"
}
```

### Интерфейс генерации PDF

**Конечная точка**: `POST /api/generate-pdf`

**Параметры запроса**:
```json
{
  "character_data": {
    "name": "Имя персонажа",
    "age": 25,
    "description": "Подробное описание персонажа"
  }
}
```

**Ответ**: возвращает файл PDF для загрузки

## Руководство по использованию

### Основные операции

1. **Начало диалога**
   - Введите вопрос или инструкцию в чат-боксе
   - Выберите язык (китайский/русский)
   - Нажмите кнопку отправки или клавишу Enter

2. **Генерация персонажа**
   - Нажмите кнопку "Сгенерировать персонажа" на боковой панели
   - Заполните основную информацию о персонаже
   - Выберите тип и страну/регион
   - Нажмите кнопку генерации

3. **Экспорт документов**
   - После генерации персонажа нажмите кнопку "Экспорт PDF"
   - Система автоматически загрузит файл PDF с карточкой персонажа

### Расширенные функции

1. **Пользовательская генерация персонажей**
   - Подробная настройка атрибутов персонажа на боковой панели
   - Поддержка выбора фэнтези-рас
   - Возможность настройки черт характера

2. **Генерация изображений**
   - Создание аватаров для сгенерированных персонажей
   - Поддержка различных стилей изображений
   - Возможность загрузки сгенерированных изображений

3. **Управление чатом**
   - Новая беседа очищает историю
   - Боковая панель может сворачиваться/разворачиваться
   - Адаптивный дизайн для различных устройств

## Часто задаваемые вопросы

### В: Сервис не запускается
**О**: Проверьте версию Python и установку зависимостей, убедитесь, что все пакеты из requirements.txt установлены правильно.

### В: Вызов API завершается неудачей
**О**: Проверьте правильность конфигурации API-ключей, проверьте нормальность сетевого соединения.

### В: Аномальное отображение интерфейса
**О**: Очистите кэш браузера, проверьте информацию об ошибках в консоли.

### В: Не удается загрузить файл
**О**: Убедитесь, что файловый сервис бэкенда работает нормально, проверьте разрешения пути к файлу.
