# Документация проекта Chatbot

## Обзор проекта

Это проект чат-бота помощника для творческого письма, предназначенный для авторов книг и сценаристов. Проект поддерживает русский и китайский языки, может генерировать информацию о персонажах, названия книг, названия городов, а также поддерживает полное создание атрибутов персонажей и экспорт в PDF.

## Функции проекта

### Основные функции
- **Генерация персонажей**: Создание полных атрибутов персонажей на основе пользовательского ввода (пол, возраст, рост, вес, цвет волос, цвет глаз, профессия, черты характера и т.д.)
- **Многоязычная поддержка**: Поддержка интерфейса и генерации контента на русском и китайском языках
- **Генерация изображений**: Создание изображений персонажей на основе описания
- **Экспорт в PDF**: Экспорт информации о персонажах в PDF-документы
- **Чат-диалог**: Функция интеллектуального помощника для чата, поддержка диалогов, связанных с творческим письмом

### Специальные функции
- **Шаблоны предустановленных персонажей**: Быстрое создание различных типов персонажей
- **Пользовательские персонажи**: Поддержка пользовательских атрибутов персонажей
- **Поддержка фэнтези-тематики**: Поддержка фэнтези-рас (эльфы, гномы, орки и т.д.)
- **Мультикультурность**: Поддержка культурного фона различных стран (Россия, Великобритания, США, Китай и др.)

## Подробное описание файлов

### main.py
- **Функция**: Бэкенд-сервер FastAPI
- **Основные конечные точки API**:
  - `POST /api/generate/character` - Генерация полного персонажа (включая изображение и PDF)
  - `POST /api/chat` - Интерфейс чат-диалога
  - `GET /file/{filename}` - Интерфейс загрузки файлов
- **Основные модули**:
  - Извлечение и генерация атрибутов персонажей
  - Вызов генерации изображений
  - Генерация PDF-документов
  - Обработка многоязычной поддержки

### index.html
- **Функция**: Пользовательский интерфейс фронтенда
- **Характеристики**:
  - Адаптивный дизайн интерфейса чата
  - Переключение между русским и китайским языками
  - Форма создания персонажей
  - Кнопки предустановленных персонажей
  - Область отображения сообщений чата

### script.js
- **Функция**: Логика взаимодействия фронтенда
- **Основные функции**:
  - Отправка и получение сообщений чата
  - Обработка форм персонажей
  - Поддержка многоязычного перевода
  - Управление загрузкой файлов
  - Обновление интерфейса в реальном времени

### style.css
- **Функция**: Дизайн интерфейса
- **Особенности дизайна**:
  - Современная синяя тема
  - Эффекты скругленных углов и теней
  - Адаптивная верстка
  - Пользовательские стили полосы прокрутки
  - Анимационные переходы

1. Установите зависимости Python:

## Руководство пользователя

### Основной процесс использования
1. **Выбор языка**: Выберите русский или китайский в правом верхнем углу интерфейса
2. **Начало диалога**: Введите вопрос или запрос в поле ввода
3. **Создание персонажа**: Используйте боковую панель формы или кнопки предустановок для создания персонажа
4. **Скачивание результатов**: Сгенерированную информацию о персонаже можно экспортировать в PDF-документ

### Опции создания персонажей
- **Предустановленные персонажи**: Быстрый выбор распространенных типов персонажей
- **Пользовательские персонажи**: Подробная настройка различных атрибутов
- **Простое описание**: Создание персонажей через описание на естественном языке

### Функции чата
- Поддержка консультаций по вопросам творческого письма
- Предоставление советов по письму и вдохновения
- Поддержка контекста многораундового диалога

## Важные замечания

- Услуга генерации изображений оплачивается по количеству точек, используйте рационально
- Сгенерированные изображения содержат идентификатор AI-генерации
- Временные файлы периодически очищаются, важные файлы скачивайте своевременно
- Убедитесь, что время сервера точно (аутентификация API чувствительна ко времени)
