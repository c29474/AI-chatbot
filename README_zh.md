# 创意写作助手 (Creative Writing Assistant)

一款专为书籍作者和编剧设计的智能聊天机器人，提供多语言支持的角色生成和创意写作辅助功能。

## 项目概述

创意写作助手是一个基于Web的AI应用，集成了星火大模型API，为作家和编剧提供以下核心功能：

- **多语言聊天界面**：支持中文和俄语
- **角色生成**：自动生成完整的角色信息（姓名、外貌、性格等）
- **创意辅助**：根据描述生成书名，或根据书名生成描述
- **文档导出**：将生成的角色信息导出为PDF格式
- **图像生成**：为角色生成对应的头像图片

## 功能特性

### 🎭 角色生成
- 自动生成姓名（姓、名、所在城市）
- 支持多种类型和国家/地区（俄罗斯、英国等）
- 奇幻题材支持（精灵、矮人等）
- 完整的角色属性：性别、年龄、身高、体重、发色、瞳色、职业、性格特征

### 💬 智能聊天
- 多语言对话支持（中文/俄语）
- 实时聊天界面
- 聊天历史管理
- 快速操作按钮

### 📄 文档管理
- PDF格式角色卡导出
- 图像生成和下载
- 文件管理功能

### 🌐 技术特性
- 响应式设计，支持桌面和移动端
- WebSocket实时通信
- RESTful API接口
- 跨域请求支持

## API接口文档

### 文本生成接口

**端点**: `POST /api/generate`

**请求参数**:
```json
{
  "prompt": "生成一个奇幻角色的描述",
  "language": "zh"
}
```

**响应**:
```json
{
  "success": true,
  "message": "生成的文本内容",
  "character": {
    "name": "角色名",
    "description": "角色描述"
  }
}
```

### 图像生成接口

**端点**: `POST /api/generate-image`

**请求参数**:
```json
{
  "prompt": "一个英俊的精灵战士",
  "size": "1024x1024"
}
```

**响应**:
```json
{
  "success": true,
  "image_url": "/files/generated_image.jpg"
}
```

### PDF生成接口

**端点**: `POST /api/generate-pdf`

**请求参数**:
```json
{
  "character_data": {
    "name": "角色名",
    "age": 25,
    "description": "角色详细描述"
  }
}
```

**响应**: 返回PDF文件下载

## 使用指南

### 基本操作

1. **开始对话**
   - 在聊天框中输入问题或指令
   - 选择语言（中文/俄语）
   - 点击发送按钮或按Enter键

2. **生成角色**
   - 点击侧边栏中的"生成角色"按钮
   - 填写角色基本信息
   - 选择类型和国家/地区
   - 点击生成按钮

3. **导出文档**
   - 生成角色后，点击"导出PDF"按钮
   - 系统将自动下载角色卡PDF文件

### 高级功能

1. **自定义角色生成**
   - 在侧边栏中详细设置角色属性
   - 支持奇幻种族选择
   - 可自定义性格特征

2. **图像生成**
   - 为生成的角色创建头像
   - 支持多种图像风格
   - 可下载生成的图片

3. **聊天管理**
   - 新建对话清空历史记录
   - 侧边栏可收起/展开
   - 响应式设计适配不同设备

## 常见问题

### Q: 服务无法启动
**A**: 检查Python版本和依赖包安装，确保所有requirements.txt中的包都已正确安装。

### Q: API调用失败
**A**: 验证API密钥配置是否正确，检查网络连接是否正常。

### Q: 界面显示异常
**A**: 清除浏览器缓存，检查控制台错误信息。

### Q: 文件下载失败
**A**: 确保后端文件服务正常运行，检查文件路径权限。
